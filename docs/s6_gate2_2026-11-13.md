# S6 闸门 2 判定（2026-11-13）

冻结深度先验可用性闸门（G2）材料提前一天齐备，当日判定。预登记判据为 OR 结构，两条均不满足，判定不通过。机制注入线按预案停止（训练此前未发射，符合「闸门通过前不启动训练」的预算纪律），转入多模态信号可用性检查。改进机制的实验设计细节按双盲纪律留在本地控制树。

## 先验接触点误差表（四档）

验证集 695 帧、约 140 万个 GT 接触点上测：

| 档 | 说明 | MAE |
|---|---|---|
| raw | 先验原样输出 | 548.8 mm（中位 +543.2 mm，系统性 ~2.2× 过远） |
| 全局标定 | 训练集拟合 1 个标量（s=0.448），预登记口径 | **107.7 mm vs 阈值 107.1 mm，边缘未过线（0.702×）** |
| 仿射（诊断档） | 训练集拟合 2 参数 s·z+t | 116.8 mm，反而劣于单标量（2 参数过拟合） |
| 逐图对齐 oracle | GT 逐图尺度+偏移，仅刻画误差结构 | 24.3 mm（约为现有回归误差 152.3 mm 的 1/6） |

- 判据 1（标定后 ≤ 0.7× 基线）：边缘未过线（两种基线口径下差均 <1 mm）。
- 判据 2（逐图偏移解释 ≥50% MSE）：26.9%，决定性不满足。
- 结构结论：可迁移的标定信息恰好就是一个全局尺度；误差无材质/距离高频结构（各材质层 518-733 mm 近似均匀）——纯全局尺度失准，域外米制标定偏大 ~2.2×。
- 诚实记录：边缘差距（0.6 mm）在帧级聚类噪声量级内，但预登记规则未设噪声带，双向事后重分析（显著性洗白 / 换拟合目标）均不采纳——判据就是判据。
